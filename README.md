# 𓃥 白六懷舊電視 (Retro TV 3D Experience)

這是一個基於 Three.js 與 WebGL 建構的 3D 復古電視互動體驗專案。專案完美還原了老式陰極射線管 (CRT) 電視的視覺質感，支援 3D 空間視角旋轉、動態跑馬燈、開關機動畫、雜訊音效及多元色調與字型自訂功能。

---

## 🌟 核心功能特色

* **3D 擬真模型與精密定位**：載入精細的復古電視 3D 模型，並將動態 Canvas 紋理完美對齊嵌合於電視螢幕中。
* **經典開關機視覺與音效**：
  * **開機**：點擊電源開關後，螢幕會先播放 **2 秒鐘的雜訊特效與立體聲雜訊沙沙聲**，隨後自動切換至流暢的跑馬燈播放。
  * **關機**：關機特效會直接在電視螢幕範圍內收縮為一條閃爍橫白線後熄滅，完美貼合電視框。
* **跑馬燈循環優化**：跑馬燈訊息在**完整離開螢幕左側**後，才會再次從右側重新開始循環跑動。
* **豐富的自訂設定選單**：
  * **文字與速度**：可自由變更跑馬燈顯示內容與滾動速度。
  * **字型與極大化尺寸**：支援多款精選字型切換，提供高達 **150px** 的極大字體選項。
  * **字體縱高比例調整**：可隨意將文字進行拉高或壓扁比例調整，適應不同的顯示區高度。
  * **色調風格（黑白灰階與復古彩色）**：支援經典灰階、純黑風格、亮白風格與彩色復古綠。
* **直覺介面設計**：
  * 浮動且可收合、拖曳的設定面板。
  * 畫面下方常駐的單一「電源開關」控制列。

---

## 🛠️ 技術堆疊

* **Three.js (r128)**：3D 場景渲染、光影與 GLB 模型載入 (`GLTFLoader`)。
* **OrbitControls**：3D 視角旋轉、縮放與平移互動。
* **HTML5 Canvas 2D API**：動態生成跑馬燈文字、雜訊圖樣與開關機 CRT 掃描線動畫。
* **Web Audio API**：即時合成白噪音（White Noise），還原真實的電視訊號沙沙音效。

---

## 🚀 專案運行方式

1. 確保本機或伺服器環境中包含以下資源檔案：
   * `index.html` (包含完整程式碼)
   * `tv__old_tv__retro_tv.glb` (電視 3D 模型檔)
2. 由於專案透過 `GLTFLoader` 載入 3D 模型，建議透過本地伺服器（例如 VS Code 的 **Live Server** 插件，或 Python 的 `http.server`）運行 `index.html`，以避免瀏覽器 CORS 跨域限制。

---

## 🎛️ 操作說明

* **旋轉視角**：按住滑鼠左鍵並拖曳（或在觸控螢幕上單指滑動）。
* **縮放視構**：使用滑鼠滾輪（或雙指縮放）。
* **電源切換**：點擊畫面下方的「電源：關閉 / 開啟」按鈕。
* **調整參數**：點擊左上角「📺 復古電視設定選單」可隨時收合、展開，並即時調整字型、大小、縱高、速度與色調風格。
